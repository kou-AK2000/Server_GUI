# 画面・操作仕様

## 目的

MVPで必要な画面構成、各画面の表示項目、操作フローを定義します。

この仕様は、`mvp-scope.md`、`data-model.md`、`validation-rules.md` に定義した内容を、利用者が操作できる画面へ対応付けるためのたたき台です。見た目のデザインや細かな文言は、プロトタイプを触りながら調整します。

## 画面一覧

| ID | 画面 | 目的 |
|---|---|---|
| SCR-001 | メイン画面 | 構成図の編集、属性編集、チェック確認、保存・出力を行う。 |
| SCR-002 | サーバー詳細パネル | 選択したサーバーのOS、ミドルウェア、ネットワーク、ストレージ情報を編集する。 |
| SCR-003 | サーバー一覧 | サーバー情報を表形式で確認する。 |
| SCR-004 | IPアドレス一覧 | IPアドレス情報を表形式で確認する。 |

MVPでは、SCR-002〜SCR-004を別ウィンドウにはしません。メイン画面上の右パネルまたは下部パネルを切り替える方式とします。

## SCR-001: メイン画面

### レイアウト

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ ファイル: 新規  開く  保存  |  編集: 元に戻す  やり直す  |  出力: CSV    │
├───────────────┬───────────────────────────────────┬─────────────────────┤
│ 部品一覧      │ 構成図キャンバス                  │ プロパティ          │
│               │                                   │                     │
│ [サーバー]    │    [Web] ── [L2SW] ── [Router]    │ 選択中: Webサーバー │
│ [L2スイッチ]  │       │                           │ 表示名              │
│ [ルーター]    │     [AP]                          │ ホスト名            │
│ [FW]          │       │                           │ IPアドレス          │
│               │     [DB]                          │ OS / CPU / メモリ   │
│               │                                   │ 詳細を開く          │
├───────────────┴───────────────────────────────────┴─────────────────────┤
│ チェック結果  警告 2件 / 情報 1件                                          │
│ ⚠ WebサーバーにIPアドレスが入力されていません。                            │
└─────────────────────────────────────────────────────────────────────────┘
```

### ヘッダー・ツールバー

| 操作 | 内容 | MVPでの扱い |
|---|---|---|
| 新規 | 空のプロジェクトを作成する。 | 実装する。未保存の変更がある場合の確認は後続で検討する。 |
| 開く | JSONファイルを選択して読み込む。 | 実装する。 |
| 保存 | 現在のプロジェクトをJSONファイルへ保存する。 | 実装する。 |
| 元に戻す | 直前の編集操作を取り消す。 | MVPの実装状況に応じて追加する。初期実装では対象外としてもよい。 |
| やり直す | 取り消した編集操作を再実行する。 | MVPの実装状況に応じて追加する。初期実装では対象外としてもよい。 |
| CSV出力 | サーバー一覧、IPアドレス一覧、接続一覧、チェック結果をCSV出力する。 | 実装する。 |

`Undo / Redo` は利用価値が高い一方で、最初の動作確認を遅らせやすいため、構成図の配置・移動・削除・接続が安定してから追加します。

### 部品一覧

部品一覧は、配置できる部品のパレットです。

| 部品 | 作成される `Component.type` | 初期表示名 |
|---|---|---|
| サーバー | `server` | サーバー |
| L2スイッチ | `l2-switch` | L2スイッチ |
| ルーター | `router` | ルーター |
| ファイアウォール | `firewall` | ファイアウォール |

### 部品追加

MVPでは、部品一覧のボタンをクリックするとキャンバス中央付近に部品を追加します。ドラッグ＆ドロップによる追加は、ボタン方式が安定してから追加します。

追加時の初期値は以下とします。

- `id`：UUIDを新規生成する。
- `diagramId`：現在の全体構成図ID。
- `displayName`：部品種別の初期表示名。
- `position`：キャンバス中央付近。既存部品と重なる場合は少しずらす。
- サーバーの `serverDetail`：各項目を空文字列で初期化する。
- ネットワーク機器の `networkDetail`：各項目を空文字列で初期化する。
- `middleware`：空配列。

### 構成図キャンバス

| 操作 | 内容 |
|---|---|
| 選択 | 部品または接続線をクリックして選択する。 |
| 移動 | 部品をドラッグして位置を変更する。 |
| 削除 | 選択中の部品または接続を削除する。部品削除時は、その部品に関係する接続も削除する。 |
| 接続 | 接続モードで接続元部品、接続先部品の順に選択し、接続を作成する。 |
| 拡大・縮小 | ボタンまたはマウスホイールで表示倍率を変更する。 |
| 移動表示 | キャンバスの空白部分をドラッグして表示位置を変更する。 |

接続作成時は、同じ部品を接続元・接続先に選択できないようにします。同じ組み合わせの接続を複数作ることは、インターフェース情報が異なる場合を考慮して許可します。

### プロパティパネル

選択中の対象に応じて表示を切り替えます。

#### サーバー選択時

| 項目 | 入力形式 | 保存先 |
|---|---|---|
| 表示名 | テキスト | `Component.displayName` |
| ホスト名 | テキスト | `ServerDetail.hostname` |
| IPアドレス | テキスト | `ServerDetail.ipAddress` |
| OS名 | テキスト | `ServerDetail.osName` |
| OSバージョン | テキスト | `ServerDetail.osVersion` |
| CPU | テキスト | `ServerDetail.cpu` |
| メモリ | テキスト | `ServerDetail.memory` |
| ディスク | テキスト | `ServerDetail.disk` |
| 用途 | テキスト | `ServerDetail.purpose` |
| 備考 | 複数行テキスト | `Component.notes` |
| 詳細を開く | ボタン | SCR-002を表示する。 |

#### ネットワーク機器選択時

| 項目 | 入力形式 | 保存先 |
|---|---|---|
| 表示名 | テキスト | `Component.displayName` |
| 管理IPアドレス | テキスト | `NetworkDetail.managementIpAddress` |
| 用途 | テキスト | `NetworkDetail.purpose` |
| 備考 | 複数行テキスト | `Component.notes` |

#### 接続選択時

| 項目 | 入力形式 | 保存先 |
|---|---|---|
| 接続元 | 読み取り専用 | `Connection.sourceComponentId` の表示名 |
| 接続先 | 読み取り専用 | `Connection.targetComponentId` の表示名 |
| 接続種別 | テキスト | `Connection.connectionType` |
| 接続元インターフェース | テキスト | `Connection.sourceInterface` |
| 接続先インターフェース | テキスト | `Connection.targetInterface` |
| 備考 | 複数行テキスト | `Connection.notes` |

#### 未選択時

`部品または接続を選択してください。` と表示します。

### チェック結果パネル

| 表示項目 | 内容 |
|---|---|
| 重要度 | `warning` または `info`。 |
| 対象 | 関連する部品の表示名。 |
| メッセージ | `validation-rules.md` で定義したメッセージ。 |

チェック結果をクリックすると、関連部品をキャンバス上で選択・強調表示します。複数部品が関連するIP重複では、全対象部品を強調表示します。

## SCR-002: サーバー詳細パネル

サーバー詳細パネルは、選択したサーバーに紐付く詳細情報を編集します。MVPでは全体構成図から独立した詳細キャンバスは作成しません。

```text
┌──────────────────────────────────────────┐
│ Webサーバー（web01）の詳細                │
├──────────────────────────────────────────┤
│ [基本情報] [ミドルウェア]                  │
├──────────────────────────────────────────┤
│ ミドルウェア                              │
│ 名称       バージョン   ポート   操作     │
│ Nginx      1.24         80,443   編集 削除│
│                                          │
│ ＋ ミドルウェアを追加                      │
├──────────────────────────────────────────┤
│ 保存                              閉じる │
└──────────────────────────────────────────┘
```

### ミドルウェア操作

| 操作 | 内容 |
|---|---|
| 追加 | 名称、バージョン、ポート、設定メモを空欄で追加する。 |
| 編集 | 対象行を編集状態にする。 |
| 削除 | 対象のミドルウェアを削除する。 |
| 保存 | `Component.middleware` を更新し、チェックを再計算する。 |
| 閉じる | 編集を確定してパネルを閉じる。未保存変更の確認は後続で検討する。 |

## SCR-003: サーバー一覧

サーバー一覧は、`Export Schema v1` の `servers[]` を画面上で確認するビューです。

| 列 | 内容 |
|---|---|
| 表示名 | 構成図上の表示名 |
| ホスト名 | ホスト名 |
| IPアドレス | 主IPアドレス |
| OS | OS名とOSバージョン |
| CPU | CPU仕様 |
| メモリ | メモリ容量 |
| ディスク | ディスク容量 |
| 用途 | 用途 |

行を選択すると、該当サーバーをメイン画面の構成図上で選択します。

## SCR-004: IPアドレス一覧

IPアドレス一覧は、`Export Schema v1` の `ipAddresses[]` を画面上で確認するビューです。

| 列 | 内容 |
|---|---|
| IPアドレス | サーバーの主IPまたはネットワーク機器の管理IP |
| 部品名 | 所有する部品の表示名 |
| 種別 | サーバー、L2スイッチなどの表示用種別 |
| ホスト名 | サーバーのホスト名。ネットワーク機器では空欄。 |
| 用途 | 用途 |

行を選択すると、該当部品をメイン画面の構成図上で選択します。

## 基本操作フロー

### 新規プロジェクト作成から保存まで

```text
新規プロジェクト
  ↓
部品を追加
  ↓
部品を選択して属性を入力
  ↓
部品間の接続を作成
  ↓
チェック結果を確認・修正
  ↓
JSONへ保存
```

### CSV出力

```text
CSV出力を選択
  ↓
チェックルールを再計算
  ↓
Export Schema v1を生成
  ↓
サーバー / IPアドレス / 接続 / チェック結果のCSVを出力
```

## 操作上の優先順位

実装は、次の順で進めます。

1. 部品追加、選択、移動、削除
2. サーバー・ネットワーク機器の属性編集
3. 接続の作成・削除・属性編集
4. JSON保存・再読込
5. チェック結果パネル
6. サーバー詳細パネルとミドルウェア編集
7. サーバー一覧・IPアドレス一覧
8. CSV出力
9. Undo / Redo、ドラッグ＆ドロップ追加などの操作改善

## MVP後に検討する画面

- 複数の詳細構成図を管理する画面
- テンプレート選択・プレビュー・インストール画面
- 設計書出力ウィザード
- カスタム部品・属性定義画面
- 変更履歴・差分比較画面
- ユーザー・権限管理画面
