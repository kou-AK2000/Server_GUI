# Orden standard template v1

これは、すぐに試せる `template.xlsx` と `mapping.json` の組です。アプリからこの2ファイルを選択すると、現在のOrdenデータを雛形の位置へ出力できます。Excelテンプレート側には、次のシートがあらかじめ含まれています。

- `表紙`
- `全体構成図`
- `サーバー一覧`
- `接続一覧`

`サーバー一覧` と `接続一覧` では、6行目を見出し、7行目からデータ用の空行にします。セルの塗り、罫線、列幅、組織ロゴなどの見た目は `template.xlsx` 側で設定します。Ordenはマッピングで指定されたセルへ値を入れるだけなので、既存帳票のレイアウトを保てます。

実際に使う際は、このフォルダをコピーしてID・バージョン・シート名・セル位置を組織の帳票に合わせて変更します。
